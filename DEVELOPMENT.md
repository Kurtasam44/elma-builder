## 🎯 Kullanım

```bash
# Kurulum
npm install

# Geliştirme
npm run dev

# Production build
npm run build
npm start
```

Tarayıcıda: `http://localhost:3000`

## 📝 Notlar

- ELMA, chat arayüzü üzerinden komut alır
- "build başlat" komutu ile 6 adımlı süreç simüle edilir
- Her adımın progress'i sidebar'da gösterilir
- Tüm loglar chat'te görüntülenir
