# ELMA Builder - Sıralı İşlem Yöneticisi

**ELMA**, chat arayüzü ile sıralı build işlemlerini yönetmek için tasarlanmış modern bir araçtır.

## 🎯 Özellikler

✅ **Chat Görünümlü Arayüz** - Doğal dil ile komut verin
✅ **6 Adımlı Build Pipeline** - Profesyonel build süreci
✅ **Real-time Progress** - Her adımın ilerlemesini izleyin
✅ **Multi-Dil Desteği** - Python, Java, C++, Go, Rust ve daha fazlası
✅ **Detaylı Loglar** - Her adımın loglarını görün

## 🚀 Build Adımları

1. **📝 Derleme (Compile)** - Kaynak kod → Makine/Ara dile
2. **🔗 Bağlama (Linking)** - Bağımlılıklar birleştirilir
3. **📦 Paketleme (Bundling)** - Tüm dosyalar tek pakete
4. **🧪 Test** - Unit, Integration, E2E testler
5. **⚡ Optimizasyon** - Minify, Tree-shaking, İyileştirmeler
6. **🎁 Artifact Üretimi** - Deploy edilebilir çıktı

## 🛠️ Teknoloji Stack

- **Frontend:** Next.js 14, TypeScript, React 18
- **Styling:** CSS-in-JS (Inline)
- **UI/UX:** GitHub Dark Theme
- **Backend:** Node.js (Genişletilebilir)

## 📦 Kurulum

```bash
npm install
npm run dev
```

Tarayıcınızda `http://localhost:3000` adresine gidin.

## 💬 Kullanım

```
Siz: "Build başlat"
ELMA: ✅ Build süreci başlıyor...
```

ELMA otomatik olarak 6 adımlı süreci başlatır ve her adımda sizi güncellemeler.

## 🎨 Ara Yüz

- **Sol Panel:** Build adımlarının durum göstergesi
- **Merkez:** Chat Mesajları
- **Alt:** Komut Giriş Alanı
